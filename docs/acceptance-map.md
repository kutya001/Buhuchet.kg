# Карта приёмки: пункт ТЗ → сквозной тест

Каждый пункт раздела ТЗ «Как проверить, что всё работает» — отдельный сквозной тест Playwright на ПК (1280 px) и телефоне (390 px). `pnpm check:acceptance` (в каждой проверке PR) падает, если у пункта нет теста, файла или названия теста. Тесты, которые меняют общую запись демо-организации (учётная политика, адрес страницы, настройки), — в файлах `e2e/*.shared.spec.ts`: они идут после всех остальных и по одному, сначала на ПК, потом на телефоне (проекты `desktop-shared` и `mobile-shared` в `e2e/playwright.config.ts`).

Формат строки: `- <пункт ТЗ> → e2e/<файл>.spec.ts › <название теста>`. Пункт, для которого тест ещё не написан: `- <пункт> → нет теста` (проверка упадёт, поэтому так пишут только в ветке, пока задача не готова).
