# Implementation Plan — Добавление Полноценного Модуля Модерации Организаций в Панель Суперадмина

Этот план описывает возвращение и расширение функционала модерации новых организаций для суперадминистратора с удобными вкладками фильтрации и действиями (Одобрить, Запросить изменения, Заблокировать).

## User Review Required

> [!IMPORTANT]
> - **Выделенный под-раздел модерации:** В модуль «Организации» добавляется фильтр-переключатель с подсвеченным счётчиком **«На модерации (X)»** для немедленного доступа к новым зарегистрированным компаниям.
> - **Полный цикл действий суперадмина:**
>   1. **Одобрить** (перевод компании в статус `active`).
>   2. **Запросить исправления** (перевод в `requires_changes` с указанием причины: например, некорректный ИНН).
>   3. **Заблокировать** (перевод в `blocked` с модераторским комментарием).
