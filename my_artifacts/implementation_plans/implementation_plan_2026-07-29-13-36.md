# Implementation Plan — UX/UI Редизайн «Парящие Матовые Островки» (Glassmorphism & Collapsible Layout)

Этот план описывает комплексный UX/UI редизайн платформы Buhuchet.kg и публичного лендинга в стиле минималистичных полупрозрачных парящих островков, внедрение сворачиваемого сайдбара, фиксированной верхней панели-островка со временем и данными компании, 3-элементного мобильного нижнего навбара и переноса меню «...» в верхний островок.

## User Review Required

> [!IMPORTANT]
> - **Стиль Полупрозрачных Матовых Островков (Glassmorphism):** Все карточки, контейнеры, панели и модальные окна переводятся в парящий стиль с эффектом `backdrop-blur-xl bg-slate-900/60 border border-slate-800/80 rounded-2xl sm:rounded-3xl shadow-2xl`.
> - **Сворачиваемый Левый Сайдбар:** Добавление кнопки сворачивания/раскрытия левой панели (`w-64` <-> `w-20` с подписями при наведении).
> - **Фиксированная Верхняя Панель-Островок:** Неуходящий при скролле скругленный матовый островок с текущей страницей, названием компании, ИНН, живыми временем/датой КР и мобильной кнопкой «...» (Еще).
> - **Мобильный Нижний Островок:** Внизу ровно 3 пункта: 1. Главная (`/dashboard`), 2. Круглая кнопка `+` (FAB) по центру для создания документа, 3. Мои контрагенты (`/dashboard/counterparties`). Меню «...» перенесено в верхнюю панель!
> - **Редизайн & Расширение Лендинга:** Публичный лендинг `app/page.tsx` получает парящие матовые островки, развернутое описание B2B сети КР, интеграцию с 1С, работу с R2 сканами и визуальные блоки.

## Verification Plan

### Automated Verification
1. Проверка типов TypeScript: `npx tsc --noEmit`
2. Продашкн сборка Next.js: `npm run build`

### Manual Verification
1. Проверка работы сворачивания левого сайдбара (клик по кнопке разворачивает/сворачивает меню).
2. Проверка фиксированного верхнего островка: во время скролла страниц панель со временем КР и инфо компании остается неподвижно на виду.
3. Проверка мобильного интерфейса: нижняя панель содержит ровно 3 пункта, при клике на `...` в верхнем островке открывается шторка всех разделов.
