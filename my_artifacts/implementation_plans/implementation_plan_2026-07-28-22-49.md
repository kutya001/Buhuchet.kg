# Implementation Plan — Продающий B2B Лендинг & Экран Регистрации / Авторизации

Этот план описывает создание современного продающего B2B-лендинга на главном роуте (`/`), обновление страниц авторизации и регистрации (`/login`, `/register`) с переключателем и автоматическим перенаправлением на онбординг юридического лица (`/onboarding`).

## User Review Required

> [!IMPORTANT]
> - **Главный роут (`/`):** На место заглушки редиректа устанавливается полнофункциональный продающий B2B-лендинг с Hero-секцией, интерактивным макетом, 4 секциями возможностей, блоком «Как это работает» и CTA-баннером.
> - **Регистрация & Переключатель (`/register` & `/login`):** Создается страница регистрации пользователя (`/register`). Добавляется удобная двухсторонняя ссылка между логином и регистрацией. При успешной регистрации пользователь сразу переправляется на онбординг организации `/onboarding`.

## Verification Plan

### Automated Verification
1. Проверка компиляции TypeScript: `npx tsc --noEmit`
2. Продашкн сборка Next.js: `npm run build`

### Manual Verification
1. Открытие главной страницы (`http://localhost:3000/`):
   - Проверка отображения лендинга, интерактивного макета и всех секций.
2. Клик на «Зарегистрироваться»: переход на `/register` -> успешное создание аккаунта -> автоматический переход на `/onboarding`.
3. Клик на «Уже есть аккаунт? Войти»: переход на `/login`.
