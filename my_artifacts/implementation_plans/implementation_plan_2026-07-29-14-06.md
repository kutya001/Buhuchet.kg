# Implementation Plan — B2B Отзыв Документов, Подробный Аналитический Дашборд & Единый Модуль Контрагентов

Этот план описывает реализацию отзыва отправленных документов для исправления ошибок, создание детальной аналитической панели организации на главной странице, обновление мобильного нижнего навбара и объединение Каталога, Заявок и Контрагентов в единый модуль с возможностью прекращения сотрудничества.

## User Review Required

> [!IMPORTANT]
> - **Нижняя Панель Навигации:** Справа в мобильном островке устанавливается **B2B Документы** (`/dashboard/documents`).
> - **Отзыв Отправленных Документов:** Добавление действия `recallB2BDocumentAction()` — отправитель может вернуть статус документа в `draft` для исправления и повторной отправки.
> - **Подробная Аналитика на Главной (`/dashboard`):** Интерактивные карточки активности, метрики входящих/исходящих документов, разбивка по статусам и динамика обработки.
> - **Единый Модуль «Контрагенты» (`/dashboard/counterparties`):** Объединение списка контрагентов, заявок сети и каталога компаний (без ИНН в каталоге) на 3 удобных вкладках + кнопка **«Прекратить сотрудничество / Деактивировать»**.

## Verification Plan

### Automated Verification
1. Проверка типов TypeScript: `npx tsc --noEmit`
2. Продашкн сборка Next.js: `npm run build`

### Manual Verification
1. Проверка отзыва документа: отправить документ, нажать «Отозвать», убедиться в смене статуса на `draft`.
2. Проверка аналитики: перейти на `/dashboard` и зафиксировать статистику по документам.
3. Проверка вкладчатого модуля контрагентов `/dashboard/counterparties` и прекращения сотрудничества.
