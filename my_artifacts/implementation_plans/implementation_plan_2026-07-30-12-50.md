# Имплементационный План: Полный Перенос и Пересборка Модуля «Организации»

Данный документ содержит архитектурный план переработки модуля из «Контрагенты» в **«Организации»** с нуля.

---

- Заголовок страницы `/dashboard/counterparties` меняется на **«Организации и Партнерство»**.

---

## 2. Структура Вкладок Модуля «Организации»

Модуль делится на 3 фундаментальные вкладки:

### 🏢 Вкладка 1: «Контрагенты»
- **Реестр активных контрагентов:**
  - На ПК — полноценная таблица Shadcn UI (Наименование, ИНН, НДС 12%, Email, Примечание, Сканы R2, Действия).
  - На мобильных — адаптивные карточки списков (Mobile Cards).
- **Создание контрагента вручную (с прикреплением файла R2):**
  - Модальное окно / Bottom Sheet с заполнением реквизитов (Наименование, ИНН КР 14 цифр, Email, Телефон, НДС 12%, Примечание).
  - **Загрузчик файлов:** Прикрепление учредительного документа (PDF, PNG, JPG), который автоматически сжимается на клиенте и загружается в Cloudflare R2!
- **Авто-создание контрагента на основе принятой заявки:**
  - При одобрении заявки партнер автоматически заносится в реестр контрагентов.
- **Поиск и Фильтрация:** Поиск по ИНН/названию/примечанию, фильтр по НДС.

---

### 📩 Вкладка 2: «Заявки»
Центр управления партнерскими заявками, разделённый на **5 статусов**:
1. **Отправлен (`pending` / `sent`)**: Ожидающие входящие и исходящие запросы (кнопки: *Принять*, *Отклонить*, *Отозвать*).
2. **Отозван (`recalled`)**: Отозванные отправителем заявки.
3. **Подтверждён (`approved`)**: Действующие одобренные партнерства (с кнопкой *Приостановить*).
4. **Отменён (`rejected`)**: Отклоненные партнерские запросы (с возможностью *Повторной отправки*).
5. **Приостановлен (`suspended`)**: Временно замороженные партнерские связи (с кнопкой *Возобновить*).

---

### 🌐 Вкладка 3: «Каталог Организаций»
- **Реестр всех организаций платформы:**
  - Поделен по **Категориям / Отраслям** (Горнодобывающая отрасль, Ритейл/Торговля, Транспорт и Логистика, IT и Телеком, Строительство, Услуги/Консалтинг, Производство).
  - На ПК — структурированная таблица организаций.
  - На мобильных — адаптивные карточки с бейджем отрасли.
- **Фильтрация и поиск:** Фильтр по выбранной отрасли и текстовый поиск по названию/ИНН.
- **Кнопки:** Запрос сотрудничества в 1 клик.
