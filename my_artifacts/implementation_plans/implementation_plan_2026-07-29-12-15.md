# Implementation Plan — Панель Суперадмина (Полный Доступ), Мобильная Адаптивность & Аудит Файлов

Этот план описывает расширение функционала панели Суперадмина (`/super-admin`) до полного управления компаниями, пользователями и R2 файлами системы, 100% мобильную адаптацию с помощью Bottom Sheets и проверку корректности сервера файлов.

## User Review Required

> [!IMPORTANT]
> - **Управление Пользователями в Суперадминке:** Добавление вкладки «Пользователи Системы» с возможностью смены ролей (`owner`/`accountant`/`manager`), привязки к организациям, назначения прав Суперадмина и удаления пользователей.
> - **Полное Редактирование Организаций:** Добавление формы редактирования всех реквизитов компании (Наименование, ИНН, Статус, Адрес, ФИО Директора, Контакты).
> - **Управление Всеми Файлами R2:** Панель просмотра, скачивания, замены и удаления файлов любой компании системы.
> - **Мобильная Адаптивность:** Трансформация модальных окон в нативные Bottom Sheets на смартфонах с тач-зонами `>= 48px`.

## Proposed Changes

### 1. Серверные Функции Суперадмина (Actions)

#### [MODIFY] [super-admin/actions.ts](file:///d:/Рабочий стол/Code Projects/Buhuchet.kg/app/super-admin/actions.ts)
- `updateCompanyAdminAction(companyId, data)`: Редактирование всех реквизитов организации.
- `getAllUsersAdminAction()`: Запрос списка всех пользователей системы с привязанными компаниями.
- `updateUserAdminAction(userId, data)`: Изменение ФИО, E-mail, Роли, привязки к Компании и флага `is_super_admin`.
- `deleteUserAdminAction(userId)`: Безопасное удаление пользователя из системы.
