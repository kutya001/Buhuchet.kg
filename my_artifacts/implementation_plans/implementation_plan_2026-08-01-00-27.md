# Implementation Plan - Бесшовное Мгновенное Переключение Табов в Панели Суперадминистратора

**Дата создания:** 2026-08-01 00:27  
**Статус:** Ожидает утверждения пользователя  

---

## 1. 🔍 Причина Задержек и Перезагрузок при Клике по Модулям
1. **Глобальный блокирующий `loading` стейт:** При переключении на табы `users`, `r2_files`, `edo_documents` вызывался глобальный `setLoading(true)`, который сбрасывал и скрывал всю страницу, заменяя её полноэкранным индиктором загрузки.
2. **Последовательные сетевые запросы по требованию:** При первом клике на вкладку выполнялся сетевой запрос к серверным Server Actions, блокируя пользователя.

---

## 2. ⚡ Техническое Решение
1. **Фоновая Бесшовная Предзагрузка (Background Prefetching):**
   - В `useEffect` при инициализации суперадминки запускается фоновая подгрузка данных для всех модулей (`getAllUsersAdminAction`, `getAllSystemFilesAction`, `getAllDocumentsAdminAction`, `file_categories`).
   - К моменту клика пользователя по любому из 7 модулей данные **уже находятся в памяти React State**, и переключение происходит **мгновенно за 0 миллисекунд (без скрытия экрана и без лоадеров)**.

2. **Точечный Локальный Loader (Local Tab Skeleton):**
   - Глобальный `loading` сбрасывается сразу после первичного получения базовой информации.
   - Если конкретная вкладка еще не завершила фоновый сетевой ответ, в ней рендерится точечный Skeleton-список, не затрагивая всю страницу и макет.

---
