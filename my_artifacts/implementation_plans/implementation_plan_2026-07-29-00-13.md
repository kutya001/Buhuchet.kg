# Implementation Plan — Ручное Сохранение Файлов, Редактирование/Замена Сканов и Панель Суперадмина

Этот план описывает отмену автоматического автосохранения сканов (перевод в явное подтверждение по кнопке «Сохранить» после выбора категории и описания), внедрение полного цикла Редактирования и Замены файлов в R2, автоматический редирект Суперадмина на `/super-admin`, добавление Реестра всех файлов системы и мобильную адаптацию панели Суперадмина.

## User Review Required

> [!IMPORTANT]
> - **Явное Сохранение Файлов (No Auto-submit):** После прямой передачи файла в Cloudflare R2 запись в `document_files` создается ТОЛЬКО после заполнения пользователем полей «Категория» и «Описание» и клика по кнопке «Сохранить».
> - **Редактирование & Замена Файла:** В карточках файлов (`/dashboard/files` и `/dashboard/company`) добавляются функции «Редактировать» (с возможностью перезагрузки нового скана в R2) и «Удалить».
> - **Суперадмин (Редирект & Файлы):** Суперадмин перенаправляется на `/super-admin`, получает вкладку «Все файлы системы» с правом управления файлами любых организаций, а вся панель оптимизирована под мобильные Bottom Sheets.

## Verification Plan

### Automated Verification
1. Проверка типов TypeScript: `npx tsc --noEmit`
2. Продашкн сборка Next.js: `npm run build`

### Manual Verification
1. Загрузка файла в R2: убедиться, что файл не создается в БД до нажатия «Сохранить».
2. Редактирование и замена файла: загрузить новый скан в R2 и проверить обновление реквизитов.
3. Логин под Суперадмином: проверить редирект на `/super-admin` и работу реестра всех файлов системы.
