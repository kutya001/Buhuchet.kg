# Implementation Plan — Устранение Мобильной Проблемы Вёрстки Панели Суперадмина

Этот план описывает устранение жесткого 240px сайдбара в `app/super-admin/layout.tsx`, который ломал мобильную верстку суперадминки на смартфонах.

## User Review Required

> [!IMPORTANT]
> - **Устранение жесткого 240px сайдбара:** В `app/super-admin/layout.tsx` убирается старый статичный сайдбар `<aside className="w-60">`, который перекрывал 70% мобильного экрана (364px).
> - **Адаптивная Шапка и Вёрстка:** Шапка суперадмина переводится на мобильный flex-wrap с высотой кнопок `min-h-[44px]`, а основной контент занимает 100% ширины мобильного устройства без сдвигов влево/вправо.
