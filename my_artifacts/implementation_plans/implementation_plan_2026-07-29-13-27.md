# Implementation Plan — Мобильная Нижняя Панель Навигации & Адаптация Суперадминки

Этот план описывает обновление мобильной навигации (круглая центральная кнопка «+» для создания документа, Главная, Контрагенты и отдельное меню «...» (Еще) в выезжающей панели), а также полную 100% мобильную адаптацию Суперадминки.

## User Review Required

> [!IMPORTANT]
> - **Центральная Круглая Кнопка «+»:** Выделенная круглая кнопка по центру нижней панели для мгновенного перехода на форму создания B2B документа (`/dashboard/documents/new`).
> - **Левая/Правая навигация:** Слева — «Главная» (`/dashboard`), Справа — «Мои контрагенты» (`/dashboard/counterparties`).
> - **Меню «...» (Еще):** Отдельная выезжающая шторка (Bottom Sheet) при клике на три точки для доступа ко всем остальным разделам (Документы, Файлы R2, Каталог, Заявки, Организация, Профиль, Выход).
> - **Мобильная Суперадминка:** 100% адаптация страницы `/super-admin` для мобильных экранов без горизонтального скролла с крупными кнопками (`>= 48px`).
