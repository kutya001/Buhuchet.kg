# Implementation Plan - Удаление упоминаний B2B и Cloudflare из Пользовательского Интерфейса

**Дата создания:** 2026-07-31 20:18  
**Статус:** Ожидает утверждения пользователя  

---

## 1. Цель рефакторинга
Очистить 100% клиентских страниц, модалок, подсказок, лендинга, авторизационных экранов, бейджей и системных сообщений от корпоративных/технических названий **B2B** и **Cloudflare**.  
Сформировать восприятие продукта как доступной **национальной платформы электронного документооборота**.

---

## 2. Карта замен терминов (Glossary Mapping)

### 2.1 Замена термина `B2B`
| Исходный текст UI | Заменяющий текст UI |
|---|---|
| `B2B Network КР` / `B2B Network` | `Платформа ЭДО КР` |
| `Вход в B2B Сеть` | `Вход в систему документооборота` |
| `B2B платформа` | `платформа электронного документооборота` |
| `B2B Отправка` / `Создание B2B Отправки` | `Отправка документа` / `Новый документ` |
| `B2B Документ №...` / `Документ B2B` | `Документ №...` / `Электронный документ` |
| `B2B Адресация` | `Адресат документа` |

### 2.2 Замена термина `Cloudflare` / `Cloudflare R2`
| Исходный текст UI | Заменяющий текст UI |
|---|---|
| `Cloudflare R2` (в бейджах и модалках) | `Облачный архив` |
| `Заменить сам скан в Cloudflare R2` | `Заменить исходный скан в хранилище` |
| `Передача файлов в Cloudflare R2...` | `Передача файлов в защищённое облако...` |
| `из Cloudflare R2` | `из защищённого архива` |
| `Отсутствует ссылка Cloudflare R2` | `Отсутствует ссылка на файл в хранилище` |

## 3. Затрагиваемые файлы

1. **Лендинг и Авторизация:**
   - `app/page.tsx` — Лендинг (Убираем B2B/Cloudflare из Hero, преимуществ и footer).
   - `app/(auth)/login/page.tsx` — Экран входа.
   - `app/(auth)/register/page.tsx` — Экран регистрации.
   - `app/layout.tsx` — Метатеги HTML head.

2. **Дашборд и Модули:**
   - `components/dashboard/DashboardShell.tsx` — Сайдбар.
   - `app/dashboard/documents/page.tsx` & `[id]/page.tsx` & `new/page.tsx` — Модуль первички.
   - `app/dashboard/company/page.tsx` — Модуль Моя Организация.
   - `app/dashboard/files/page.tsx` — Модуль Реестр файлов.
   - `components/documents/MultiFileDropzone.tsx` & `ScanViewer.tsx` — Модули сканера и загрузки.
   - `components/ui/MobileFAB.tsx` — Мобильная кнопка быстрых действий.
