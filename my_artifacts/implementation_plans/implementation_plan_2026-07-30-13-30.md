# Имплементационный План: Глубокая Доработка Модуля «Реестр Файлов»

Данный документ содержит архитектурный план доработки модуля **«Реестр Файлов»** (`/dashboard/files`) с атрибутами источников, ссылками, контролем владения файлами организации, калькулятором дискового пространства и блоком аналитической статистики.

---

## 🏢 1. Требования и Архитектура

### 1.1 Атрибут «Вид Источника» (`sourceType`)
Каждый файл классифицируется по одному из 4 видов источников:
1. 📝 **Файл из документа:** Прикреплен к B2B накладной/акту (`document_id != null`).
2. 🏛️ **Файл моей организации:** Уставной документ компании (`is_legal_doc == true` & `company_id == myCompanyId`).
3. 🤝 **Файл контрагента:** Учредительный документ контрагента.
4. 📂 **Файл вручную добавленный:** Файл из собственного архива (`document_id == null` & `is_legal_doc == false`).

### 1.2 Атрибут «Источник» (`sourceUrl` & Навигация)
Интерактивные ссылки для перехода непосредственно к первоисточнику файла:
- Ссылка на B2B Документ: `/dashboard/documents/${document_id}`
- Ссылка на Мою Организацию: `/dashboard/company`
- Ссылка на Контрагента: `/dashboard/counterparties?search=${inn}`

### 1.3 Фильтр контроля владения («Только файлы моей организации»)
- Быстрый переключатель (Toggle Switch), фильтрующий файлы strictly загруженные текущей компанией (`company_id == myCompanyId`).

### 1.4 Калькулятор Объема и Подсчет Файлов
- Информационные карточки: **Общее число файлов** (например, `48 файлов`) и **Суммарный занимаемый объём** (например, `18.4 MB` / `10 GB`).

### 1.5 Статистика по файлам (Аналитический Блок)
- Визуальные диаграммы/плашки со статистикой:
  - Статистика по Видам Источников (Документы / Уставные / Контрагенты / Архив).
  - Статистика по Видам / Типам (PDF документы / Изображения PNG, JPG / Иное).
