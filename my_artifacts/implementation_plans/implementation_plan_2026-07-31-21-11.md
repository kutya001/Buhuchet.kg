# Implementation Plan - Упрощенный UX Привязки Telegram и Копирование Кода в 1 Клик

**Дата создания:** 2026-07-31 21:11  
**Статус:** Ожидает утверждения пользователя  

---

## 1. Изменения в Генерации Ссылки (`app/dashboard/profile/telegram-actions.ts`)
- Генерация `deepLink` изменится с `https://t.me/BotName?start=XXXX` на чистую ссылку на бота: `https://t.me/BotName`.

---

## 2. Обновление Логики Webhook (`app/api/telegram/webhook/route.ts`)
- **При отправке команды `/start`:**
  - Бот всегда отвечает с запросом ввода кода:  
    *"👋 **Добро пожаловать в Buhuchet.kg!**\n\nПожалуйста, введите 4-значный код подтверждения из вашего личного кабинета."*
- **При отправке 4-значного кода (например `8737`):**
  - Вебхук производит поиск кода в `telegram_verification_codes`.
  - При успешном совпадении создает запись в `telegram_connections` и пишет:  
    *"✅ **Аккаунт успешно привязан!**\n\nВы будете получать уведомления для компании **ООО «...»**."*

---

## 3. Обновление UI Компонента (`components/dashboard/TelegramBindingCard.tsx`)
- **Копирование кода в 1 клик:**
  - При клике по блоку с 4-значным кодом вызывается `navigator.clipboard.writeText(code)`.
  - Показывается бейдж «Скопировано в буфер обмена!».
- Кнопка перехода ведет на чистый чат с ботом без передачи кода.

---

## 4. План Валидации
1. Проверка сборки `npm run build`.
2. Фиксация изменений в Git (`git push origin main`).
