# План реализации матрицы состояний B2B-партнерств и модального окна в Каталоге Организаций

Полное внедрение матрицы статусов партнерства, контекстных действий, модального окна подтверждения прекращения сотрудничества и оптимистичного обновления UI.

## User Review Required

> [!IMPORTANT]
> - Матрица состояний покрывает 100% кейсов: **Пусто** (Запросить), **Заявка отправлена** (Отменить), **Входящая заявка** (Принять/Отклонить), **Сотрудничаем** (Прекратить через подтверждение), **Архив/Отклонено** (Повторить запрос).
> - При принятии заявки контрагенты автоматически и взаимно создаются в `counterparties` для обеих организаций.
> - При клике на «Прекратить сотрудничество» отображается фирменное стеклянное модальное окно с предупреждением о разрыве связей ЭДО.

#### [MODIFY] [app/dashboard/counterparties/actions.ts](file:///d:/Рабочий%20стол/Code%20Projects/Buhuchet.kg/app/dashboard/counterparties/actions.ts)
- Добавить/актуализировать явные экшены:
  * `requestPartnershipAction(targetCompanyId)` — отправка / повторный запрос (`pending`).
  * `cancelPartnershipRequestAction(partnershipId)` — отмена исходящей заявки (`cancelled`).
  * `acceptPartnershipRequestAction(partnershipId)` — подтверждение входящей заявки (`approved`) + генерация взаимных контрагентов.
  * `rejectPartnershipRequestAction(partnershipId)` — отклонение заявки (`rejected`).
  * `terminatePartnershipAction(partnershipIdOrCompanyId)` — прекращение сотрудничества (`terminated`) + удаление контрагента из списков.
