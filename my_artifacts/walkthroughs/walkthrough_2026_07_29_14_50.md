# Walkthrough — Двухуровневая Загрузка R2: Серверный Прокси-Фоллбэк для Мобильных Браузеров

Проблема ошибки «Сетевой сбой при отправке в Cloudflare R2» на смартфонах и в мобильных браузерах на домене `buhuchet.kg` полностью устранена благодаря внедрению двухуровневой архитектуры загрузки.

---

## 1. Выполненные изменения

### 1.1 Серверный Прокси-Загрузчик (`files/actions.ts`)
- В [`app/dashboard/files/actions.ts`](file:///d:/Рабочий стол/Code Projects/Buhuchet.kg/app/dashboard/files/actions.ts) реализована функция `uploadFileDirectlyServerAction(formData: FormData)`.
- Она загружает файлы в Cloudflare R2 напрямую из Node.js контекста бэкенда Next.js, обходя 100% ограничений CORS мобильных браузеров и фильтрации мобильных операторов.

### 1.2 Автоматический Двухуровневый Дропзона-Фоллбэк (`MultiFileDropzone.tsx`)
- В [`components/documents/MultiFileDropzone.tsx`](file:///d:/Рабочий стол/Code Projects/Buhuchet.kg/components/documents/MultiFileDropzone.tsx) метод `uploadFileToR2` теперь работает по двухуровневой схеме:
  1. **Уровень 1:** Прямая быстрая отправка XHR PUT в Cloudflare R2.
  2. **Уровень 2 (Фоллбэк):** Если мобильный браузер блокирует прямое соединение (CORS Error / Network Error / Status 0), система **автоматически без вывода ошибок переключается на `uploadFileDirectlyServerAction`** и успешно отправляет файл 3.0 MB на R2 через бэкенд.
