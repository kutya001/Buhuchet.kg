# Отчет о выполненных изменениях: Расширение вкладок Каталога и автоматическое создание контрагентов для ЭДО

## Выполненные работы

1. **Вкладка «Каталог Организаций» (`app/dashboard/counterparties/page.tsx`)**:
   - Реализована интерактивная ячейка взаимодействия B2B партнерства для каждой компании каталога:
     * **Отсутствие партнерства**: кнопка `🤝 Отправить заявку B2B`.
     * **Исходящая заявка в процессе**: статус `⏳ Заявка отправлена` + кнопка `❌ Отозвать`.
     * **Входящая заявка от компании**: кнопки `✅ Принять` и `❌ Отклонить`.
     * **Подтвержденное партнерство (Уже сотрудничает)**: плашка `🤝 В сети партнеров` + кнопка `🚫 Прекратить сотрудничество`.

2. **Автоматическое создание контрагента в реестре (`app/dashboard/counterparties/actions.ts`)**:
   - При одобрении заявки (`respondToPartnershipRequestAction`) выполняется двусторонняя запись в `public.counterparties` через `ensureCounterpartyLink`.
   - Взаимные записи гарантированно создаются и связываются по `target_company_id`.
   - При прекращении сотрудничества (`terminatePartnershipAction`) связывающие записи удаляются из `public.counterparties` и `public.company_partnerships`.

3. **Форма создания B2B документа (`app/dashboard/documents/new/page.tsx`)**:
   - Обновлен запрос выборки доступных контрагентов: подтягиваются все компании со статусами партнерства `approved` и `accepted`, а также записи из справочника `counterparties`.
   - Новые подтвержденные контрагенты мгновенно становятся доступны в выпадающем списке выбора получателя первички.

## Проверка
- Проверка типов TypeScript завершена без ошибок (`tsc --noEmit`, exit code 0).
