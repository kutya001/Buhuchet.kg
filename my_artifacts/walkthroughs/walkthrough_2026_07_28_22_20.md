# Walkthrough — Завершение Интеграции Cloudflare R2 Хранилища

Интеграция облачного S3-совместимого хранилища **Cloudflare R2** вместо моковой загрузки полностью завершена.

## 1. Реализованные шаги и модули

### 1.1 S3 SDK & Подключение (`lib/r2.ts`)
- Установлены пакеты `@aws-sdk/client-s3` и `@aws-sdk/s3-request-presigner`.
- Создан модуль [`lib/r2.ts`](file:///d:/Рабочий стол/Code Projects/Buhuchet.kg/lib/r2.ts) для инициализации S3-клиента на основе `R2_ACCOUNT_ID`, `R2_BUCKET_NAME`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_ENDPOINT`.

### 1.2 Server Actions для Presigned URLs (`app/dashboard/files/actions.ts`)
- **`getPresignedUploadUrlAction(fileName, fileType)`:** Генерирует временную PUT-ссылку (15 минут) для прямого отправления файла из браузера. Ключ хранения: `companies/{company_id}/{YYYY}/{MM}/{uuid}-{fileName}`.
- **`getPresignedDownloadUrlAction(fileKey)`:** Генерирует временную GET-ссылку (60 минут) для безопасного просмотра и скачивания сканов из R2.

### 1.3 Реальная прямая загрузка в `MultiFileDropzone.tsx`
- Файлы отправляются напрямую из браузера пользователем в Cloudflare R2 по выданному Presigned URL через `XMLHttpRequest`.
- Выполняется точное отслеживание реального процента прогресса (0-100%).
- Метаданные `file_path_r2`, `file_name`, `file_size`, `file_type` передаются в `document_files`.

### 1.4 Предпросмотр и скачивание в `ScanViewer.tsx` & Реестрах
- В просмотрщике [`ScanViewer.tsx`](file:///d:/Рабочий стол/Code Projects/Buhuchet.kg/components/documents/ScanViewer.tsx) и реестре файлов [`/dashboard/files`](file:///d:/Рабочий стол/Code Projects/Buhuchet.kg/app/dashboard/files/page.tsx) добавлены кнопки прямой загрузки и просмотра оригинала скана из Cloudflare R2 по подписанным ссылкам.

### 1.5 Конфигурация
