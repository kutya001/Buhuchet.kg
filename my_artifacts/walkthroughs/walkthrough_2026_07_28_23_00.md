# Walkthrough — Завершение Разработки Личного Архива & Учредительных Документов

Все задачи по созданию Личного архива файлов компании, хранению учредительных документов и повторному использованию R2-сканов при отправке B2B документов успешно выполнены.

## 1. Выполненные работы

### 1.1 Схема Базы Данных & DDL (Supabase)
- Поле `document_id` в `document_files` переведено в категорию необязательных (`NULLABLE`).
- Добавлены колонки `company_id` (привязка файлов к организации), `is_internal` (флаг личного архива), `is_legal_doc` (флаг учредительных документов).
- Добавлены справочные категории уставных сканов (*Устав компании, Свидетельство ЮЛ, Паспорт руководителя, Паспорт учредителя, Справка ГНС / Соцфонд*).

### 1.2 Серверные Экшены (`app/dashboard/files/archive-actions.ts`)
- `uploadFileToArchiveAction`: Сохранение скана в личный архив без привязки к B2B отправке (`is_internal = true`, `document_id = null`).
- `getCompanyFilesArchiveAction`: Получение всех имеющихся сканов организации для быстрого выбора.
