# Walkthrough - Устранение Ошибки Check Constraint `company_partnerships_status_check`

**Дата и время:** 2026-08-06 21:46  
**Статус:** Исправлено & Проверено  

## Описание Проблемы
При попытке смены статуса заявки партнерства (например, подтверждение или отмена) СУБД отбивала операцию с ошибкой:
`new row for relation "company_partnerships" violates check constraint "company_partnerships_status_check"`.

### Причина
В Check Constraint таблицы `company_partnerships` в PostgreSQL не были включены статусы `'approved'`, `'sent'`, `'recalled'`, `'suspended'`, отсылаемые из Server Actions `app/dashboard/counterparties/actions.ts` и `types/database.types.ts`.

---

## Что было сделано

1. **🛠️ Создана инкрементальная миграция `./DATABASE/changes/004_fix_company_partnerships_status_check.sql`:**
   ```sql
   ALTER TABLE public.company_partnerships
   DROP CONSTRAINT IF EXISTS company_partnerships_status_check;

   ALTER TABLE public.company_partnerships
   ADD CONSTRAINT company_partnerships_status_check
   CHECK (status IN ('pending', 'approved', 'accepted', 'rejected', 'cancelled', 'sent', 'recalled', 'suspended'));
   ```

2. **🗄️ Обновлена сводная схема `./DATABASE/schema.sql`:**
   - В определение таблицы `company_partnerships` внесен расширенный `CHECK` constraint.

3. **📚 Актуализирована документация `./DATABASE/DATABASE_DOCUMENTATION.md`:**
   - В описании таблицы `company_partnerships` отражен новый перечень допустимых значений статусов.
