# Walkthrough — Панель Суперадмина (Полный Доступ), Мобильная Верстка & Аудит Файлов

Все задачи по расширению функций Панели Суперадмина (`/super-admin`), внедрению полноценного управления компаниями, пользователями и R2 файлами системы, а также 100% нативной мобильной адаптивности выполнены.

---

## 1. Реализованный функционал

### 1.1 Управление Пользователями Системы (`/super-admin`)
- Добавлена новая вкладка **«Пользователи Системы»** (`all_users`) с глобальным поиском по имени, e-mail и названию привязанной организации.
- **Модальное окно пользователя:**
  - Полное изменение ФИО, E-mail, Роли (`owner`, `accountant`, `manager`), перепривязка к любой организации из списка и переключение прав Суперадмина (`is_super_admin`).
- Добавлена кнопка **Удаления пользователя** из системы (удаляет записи из `auth.users` и `public.users`).

### 1.2 Полный Доступ на Редактирование Организаций
- На вкладке «Все Организации» добавлена кнопка **«Редактировать»**.
- Модальное окно редактирования компании позволяет изменять:
  - Официальное Наименование, ИНН (14 цифр), Отрасль.
  - Статус верификации (`active`, `pending_approval`, `requires_changes`, `blocked`).
  - Юридический адрес, ФИО руководителя, E-mail и Телефон.

### 1.3 Управление Всеми Файлами R2 в Системе
- Вкладка **«Все Файлы R2»** позволяет Суперадмину:
  - Искать файлы любой компании системы по наименованию, описанию или ИНН организации.
  - Просматривать и скачивать любой файл R2 по генерируемой Presigned ссылке.
  - Редактировать реквизиты скана и **заменять сам файл** в Cloudflare R2 с автоматической обновой метаданных.
  - Удалять любой файл из системы.

### 1.4 Кросс-платформенная Нативная Мобильная Адаптивность
- Все модальные окна на экранах смартфонов (`< 768px`) преобразуются в нативные мобильные **Bottom Sheets** с визуальными плашками-индикаторами свайпа.
- Все кнопки и поля ввода приведены к минимальной высоте **`>= 48px`** для комфортного нажатия с сенсорных экранов смартфонов (iOS / Android).
