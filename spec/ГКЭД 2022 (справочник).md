#### ГКЭД 2022 (справочник)

Государственный классификатор видов экономической деятельности Кыргызской Республики, редакция 2022 года, перенесённый полностью из файла пользователя «ГКЭД 2022.pdf» (загружен 18.10.2026). Файл — источник для `data/gkedDB.json` прототипа; справочник ведёт только администратор платформы в «Справочники платформы», организации его только выбирают. Готовые JSON для прототипа: `tz/data/gkedDB.json` (записи) и `tz/data/gkedLinks.json` (связи с налогами, режимами, льготами и видами отчётов).

##### Как читать файл

- **Ключ раздела** — `gked` (в `tz/data/gkedDB.json` массив называется `items`): один массив всех записей классификатора
- **Поля записи**
	- код (`code`) — как в классификаторе: секция — буква (`A`), подсекция — две буквы (`CA`), раздел — две цифры (`10`), группа — `10.1`, класс — `10.11`, подкласс — `10.11.1`
	- название (`name`) — дословно из файла пользователя; переносы строк и разорванные дефисы склеены
	- уровень (`level`) — `section` секция, `subsection` подсекция, `division` раздел, `group` группа, `class` класс, `subclass` подкласс
	- родитель (`parent`) — код записи уровнем выше; у раздела — подсекция, если она есть (`10` → `CA`), иначе секция (`01` → `A`); у секции родителя нет
	- секция (`section`) — буква секции, для быстрого фильтра
	- признак действия (`active`) — у всех записей `true`: в файле пользователя колонки действия нет, все коды редакции 2022 года действуют **(сверить с Нацстаткомом, нет ли отменённых кодов)**; отменённый код потом не удаляется, а отключается, чтобы старые карточки контрагентов не потеряли ссылку
	- можно выбрать (`selectable`) — `true` только у подклассов **(по умолчанию)**: у контрагента основной и дополнительные ГКЭД выбираются на самом нижнем уровне, как в регистрационных документах; верхние уровни служат для поиска по дереву и для префиксов в связях с налогами
- **Префикс** — в связях с налогами, режимами и льготами (раздел «Связь ГКЭД с налогами, режимами и льготами» в «Справочники платформы (исчерпывающие).md») код любого уровня означает «этот код и всё, что ниже»: `47` — вся розничная торговля, `62.01` — `62.01` и `62.01.0`; буква — вся секция
- **Состав**: всего 1815 записей — секций 21, подсекций 21, разделов 88, групп 272, классов 613, подклассов 800; у каждой записи, кроме секций, есть родитель, все коды уникальны, у каждого класса есть хотя бы один подкласс
- **Порядок** — как в классификаторе; ниже записи сгруппированы по секциям, вложенность строк повторяет дерево
