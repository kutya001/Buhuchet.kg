# packages/domain — бизнес-правила

- Чистый TypeScript: никакой базы, сети, файлов, времени «сейчас» и фреймворков. Нельзя импортировать `@buhuchet/db`, `@buhuchet/adapters`, `@buhuchet/api`, `hono`, `drizzle-orm`, `postgres`, `node:*` (проверяет ESLint).
- «Сегодня» и «сейчас» приходят параметром (их даёт `clock` из `@buhuchet/adapters`), поэтому любая функция проверяется тестом с фиксированной датой.
- Деньги — целые тыйыны (`number`, `Number.isSafeInteger`), на экран — через `formatSom`. Дробные сомы в расчётах не держим.
- Даты сроков — строки `YYYY-MM-DD` (тип `IsoDate`), считаются по Бишкеку (UTC+6).
- Источник правил — раздел ТЗ модуля в `spec/` и файлы прототипа `spec/prototype/src/js/core/*.js`, `spec/prototype/src/js/modules/*.js`. Эталонные ответы для тестов берутся из прототипа (скилл `prototype-oracle`).
- Порог покрытия тестами — 80 % (`pnpm --filter @buhuchet/domain test:coverage`); падение ниже останавливает слияние.
- Тексты экранов по умолчанию (начальное наполнение словаря) — `UI_TEXTS` в `src/l10n/texts.ts`, тексты модуля — своим файлом `src/l10n/<модуль>-texts.ts` (в `texts.ts` — одна строка модуля); сообщения правил домена (ошибки проверок) пока остаются в модулях домена (docs/decisions.md, п. 24).
- Файлы раскладываются по модулям ТЗ: `src/<модуль>/…` (`reports`, `contractors`, `money`, …); общие кирпичи — в `src/common/`.
- Списки — `src/common/list.ts`: размеры страниц и «Все записи» (не больше 5 000 строк), `pageCount`, `shownRange`, сортировка по кругу `nextSort`, типы столбцов и фильтров, поиск как в прототипе `matchesSearch` (эталон для SQL), группировка `toggleGroupLevel` / `groupLevels` и итоги групп `groupAggOf` (по умолчанию сумма у числовых), предел выгрузки `EXPORT_ROWS_LIMIT`, настройки вида `GridViewSettings`, ключи списков `GRID_KEYS` (новый список с настройками вида — новый ключ) и «Статистики» модуля `statsViewKey` / `statsShown` (`isViewKey` — оба вида), формы числа `pluralForm`, число с разрядами `formatCount`.
- Шкалы статусов — `src/common/status.ts` (прототип `ui/status-scale.js`): `STATUS_SCALE_DEFS` (шаги, боковые, «Не требуется», отметки, цвет и значок), `scalePosition`, `scaleNext`, `scaleBack`, `rollbackRefusal`, `statusDurations`, `statusTotals`, `durationText`; названия статусов — ключи словаря `status.<шкала>.<код>` (`src/l10n/status-texts.ts`). Ответы сверены с прототипом: `scripts/oracle-status.mjs` пишет `src/common/__fixtures__/status-scales.json`.
- Справочники платформы — `src/platform-dicts/`: списки значений каталога (`catalog.ts`: виды периодичности, действия, группы выбора, режимы, льготы, …) и производственный календарь (`calendar.ts`, прототип `core/reference.js`): `productionCalendar`, `isWorkingDay`, `nextWorkingDay` (перенос срока с выходного), `calendarYear` (дни года для ответа API), `calendarEntryProblem` (проверка записи при наполнении). Ответы сверены с прототипом: `scripts/oracle-calendar.mjs` пишет `src/platform-dicts/__fixtures__/calendar.json`.
- Справочники организации — `src/dicts/`: сроки словами (`report-types.ts`: `dueRuleText`, `payRuleText`, `paysText`, прототип `ruleText`, `payRuleText`), правила подключения и настроек вида (`org-report-types.ts`: `orgReportTypeProblem`), группы окна «Выбор налогов» (`tax-pick.ts`: `taxPickGroups`, `mainTaxPicks`, прототип `txGroups`, `txMain`). «Справочники платформы» для организации (`platform-dicts.ts`): плитки по группам (`orgDictGroups`), столбцы окон (`ORG_DICT_COLUMNS`), справочники «Поиска по всем значениям» (`ALL_VALUES_DICTS`), справочники запроса «Попросить добавить» (`DICT_REQUEST_DICTS`); описания значений (`value-guide.ts`: «Меняет сроки» льготы `benefitDueText`, строки суммы ставки ЕН `singleTaxRateParts`, прототип `benOvTxt`, `rtParts`). Ответы сверены с прототипом: `scripts/oracle-report-rules.mjs`, `scripts/oracle-tax-pick.mjs` и `scripts/oracle-value-guide.mjs` пишут `src/dicts/__fixtures__/`.
- Деньги — `src/money/requisites.ts` (прототип `core/requisites.js`): виды реквизита и назначения счёта, проверка `requisiteProblems` (в форме и на сервере), `normalizeRequisite`, строки для экрана (`requisiteText`, `requisiteNumberText`), «Основной» (`orgAccountMains`, `walletMains`, прототип `rqMainFix`), выбор банков (`bankChoices`), реквизиты для налогов контрагента (`taxRequisiteChoices`, `mainTaxRequisite`) и предупреждение при удалении последнего счёта для налогов (`lastTaxAccountWarning`).
- Файлы — `src/files/files.ts` (прототип `modules/files.js`): предел 20 МБ, тип по расширению и запрещённые типы (`fileUploadProblem`, docs/deviations.md п. Г-1), размер словами (`fileSizeParts`, прототип `fmtSize`), удаление своего файла в течение суток (`fileDeleteRefusal`), виды записей-источников `FILE_SOURCE_KINDS`.
