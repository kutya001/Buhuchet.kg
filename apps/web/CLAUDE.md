# apps/web — интерфейс Next.js

- App Router, React, TypeScript, Tailwind CSS v4. Сборка `output: "standalone"` — тот же сайт на Vercel и в Docker.
- API — только пакет `@buhuchet/api`, подключён одним файлом `app/api/[[...route]]/route.ts` (runtime `nodejs`). Своих серверных обработчиков данных здесь нет.
- Запрещено: Server Actions для данных (`"use server"`), Edge Runtime (`export const runtime = 'edge'`), прямые запросы к базе из компонентов, `@vercel/*` и `@supabase/*` (проверяет `pnpm check:portability`).
- Страницы за входом работают как одностраничное приложение: данные берут из API типизированным клиентом Hono (`src/api-client.ts`), позже — через TanStack Query; формы — React Hook Form со схемами Zod из `@buhuchet/shared`.
- Сохранение записи с версией: ответ 409 (`isRecordChanged` из `@buhuchet/shared`) — правка не сохранена; над формой `RecordChangedNotice` из `@buhuchet/ui`, «Перечитать» заново загружает запись (новая версия и значения), пользователь правит снова. Молча повторять запрос с новой версией нельзя.
- Тексты интерфейса — только из словаря (модуль «Локализация»): новый текст — ключ с русским текстом в `UI_TEXTS` (`packages/domain/src/l10n/texts.ts`), на экране — `const t = useT(); t('ключ', { имя: значение })` (`src/l10n/provider.tsx`), в серверном компоненте — `await getT()` (`src/l10n/server.ts`). Строки с русскими буквами в коде сайта запрещает ESLint (комментарии и названия тестов можно).
- Словарь приходит в первом ответе страницы: корневой макет (`app/layout.tsx`) читает его на сервере методом `/api/l10n` через API в том же процессе — к базе страница не обращается. Ошибку ответа API экран показывает из словаря по коду (`err.<код>`), текст ответа — только если ключа нет.
- Как в прототипе: граница ПК и телефона 768 px, на телефоне нижняя панель ровно из 4 модулей и «≡ Другие модули», у каждой карточки «На весь экран». Сверяться с `spec/prototype/src/js/ui` и `spec/prototype/src/css`.
- Экраны раскладываются по модулям ТЗ: `app/(app)/<модуль>/…`; общие компоненты — в `packages/ui`.
- `vercel.json` — регион dub1 (как у базы стенда, docs/deviations.md п. 1) и вызов `/api/cron/tick` раз в минуту; сверяется с `PLATFORM_CRON_ENTRIES` тестом.
