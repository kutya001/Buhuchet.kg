# Переезд на VPS

Полная инструкция — `docs/migration-vps.md`; она обновляется вместе с кодом. Коротко:

1. Подготовить VPS (Ubuntu 24.04, Docker, файрвол: 80, 443, SSH по ключу), скопировать `docker-compose.prod.yml`, `docker/Caddyfile` и файл переменных окружения.
2. Запустить пустую копию, проверить `/api/health`.
3. Файлы: `rclone sync` из S3 Supabase в MinIO — заранее, затем ещё раз в окно переезда.
4. Окно переезда: режим работ, остановить запись, `pg_dump` из Supabase → `pg_restore` на VPS, повторный `rclone sync`.
5. Проверить: число записей по таблицам, сквозные тесты против VPS (`E2E_BASE_URL=https://… pnpm test:e2e`), вход и скачивание файла.
6. Переключить записи DNS в кабинете cctld.kg на адрес VPS; заново задать вебхук Telegram.
7. Выключить Vercel Cron (удалить проект или crons), включить worker.
8. Две недели держать Vercel и Supabase «только чтение» как запасной вариант.

Репетиция — на тестовом стенде до первого выпуска и раз в квартал. Claude Code готовит команды и проверяет, но DNS, ключи и рабочую базу меняет заказчик или GitHub Actions.
