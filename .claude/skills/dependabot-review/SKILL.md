# PR Dependabot

Dependabot открывает PR по понедельникам. У такого PR `pr-policy` красный, пока Claude не проверил его и не дописал «Отчёт ревьюеров» с проверенным коммитом (docs/decisions.md п. О-40): это норма, а не поломка (docs/typical-mistakes.md № 24). Порядок — `docs/deploy.md`, раздел «Обновления зависимостей»: PR с пакетами после отчёта сливается сам; PR с actions меняет `.github/` — его сливает только заказчик.

## Порядок
1. Открытые PR от `dependabot[bot]`; у каждого — SHA головы PR (последний коммит).
2. **Что обновилось.** Пакеты и версии из описания и `git diff`; для мажорных версий — список ломающих изменений из заметок выпуска и где этот пакет у нас используется.
3. **Действия GitHub** (`.github/workflows`): новая ссылка — полный SHA, и он совпадает с тегом из комментария (`git ls-remote https://github.com/<действие> 'refs/tags/<тег>' 'refs/tags/<тег>^{}'` — у аннотированного тега коммит в строке с `^{}`); новые входы и выходы действия не ломают наши шаги; `permissions` не расширились.
4. **CI зелёный** на этом коммите: `check` и `docker-e2e`. Красный — скилл `ci-red`; ломающее изменение, которое правится кодом, — отдельным PR сессии, а не в ветку Dependabot.
5. **Отчёт.** Переименовать PR по-русски (имя PR станет коммитом в main): «Зависимости: …», «CI: …». В описание PR — раздел «## Отчёт ревьюеров» со строками `- spec-reviewer: соответствует — …`, `- security-reviewer: замечаний нет; критично: нет — …` и `- проверен коммит: <SHA головы>`. Вердикты — выводы запущенных агентов (`spec-reviewer`, `security-reviewer`, в том числе про `postinstall` новых пакетов), а не готовый шаблон. Новый пуш Dependabot в PR — проверка и строка с SHA заново.
6. Ветка отстала от main — комментарий `@dependabot rebase` в PR. Кнопку «Update branch» не нажимать и main в ветку не сливать: Dependabot перестанет вести этот PR. Старшую версию, которая требует правок кода, закрыть и сделать отдельной задачей.
7. Заказчику — одна строка: какие PR проверены и сольются сами, какие (с `.github/`) ждут его слияния, какие не проходят и почему.
