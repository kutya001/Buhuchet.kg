# Расхождение с ТЗ

1. Не выбирать вариант молча. Если задачу можно продолжить, временно сделать по ТЗ (ТЗ главнее прототипа), если ТЗ молчит — по прототипу; в коде — комментарий `// ОТКЛОНЕНИЕ: docs/deviations.md#<номер>`.
2. Добавить запись в `docs/deviations.md` по шаблону из файла: номер, модуль, что в ТЗ (цитата и раздел), что в прототипе (файл и функция), что сделано в продукте, вопрос заказчику с вариантами и рекомендацией.
3. В описании PR — раздел «Вопросы к ТЗ» со ссылкой на запись.
4. В отчёте заказчику — вопрос простыми словами, один на расхождение, с рекомендуемым вариантом.
5. После ответа: запись получает «Решение (дата)», код — по решению, а правку ТЗ готовит тред «Техническое задание» (spec/ меняется только через `pnpm spec:sync` после правки ТЗ в репозитории прототипа).
